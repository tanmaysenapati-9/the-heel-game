### THE STORY
Achilles was nearly invincible — every part of his body was unbeatable except one small spot on his heel, which was never protected. That single weak point was eventually what killed him.

In cybersecurity, finance, fitness, and life — a system can be strong everywhere except one overlooked spot, and that is exactly where it fails.

### THE PROBLEM WE SOLVE
Modern scanners report 100s of vulnerabilities. But what if 99.9% of your system is secure and you miss the *ONE* flaw that matters? **THE HEEL** hunts for that single overlooked vulnerability in an otherwise solid system.

### WHAT WE BUILT
An interactive, high-fidelity vulnerability hunting game that simulates real-world security auditing.

**You are the analyst. Your job: find the heel before the system collapses.**

#### 🎮 4 Levels:
1.  **THE TITAN (Biometric Scan):** Wireframe human armor — all plates secure except a torn Achilles tendon. Use the thermal scanner lens.
2.  **THE FORTRESS (Network):** 10-node enterprise network, all firewalled. One node has SSH port 22 left open to the world.
3.  **THE VAULT (FinTech):** Personal finance dashboard looks perfect. One hidden recurring subscription is bleeding $847/month.
4.  **THE COLOSSUS (Infra):** Final boss. Scrolling server logs — find the leaked `STRIPE_API_KEY` in an ENV file.

### ✨ Features
- Custom crosshair scanner that reveals hidden flaws
- Real-time System Integrity meter (99.8% -> FAIL)
- Cinematic glitch effects, particle systems, glassmorphism UI
- Terminal log simulation, radar ping, threat level indicators
- Fully responsive — works on mobile + desktop
- No frameworks — pure HTML/CSS/JS, loads in <1s

### 🛠️ Tech Stack
- Frontend: Vanilla JS, Canvas API for particles

- Fonts: Space Grotesk + JetBrains Mono
